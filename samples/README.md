# Sample data

**Every file in this folder is synthetic.** Names, companies, addresses, phone
numbers, references, amounts and dates were generated by `npm run samples` (see
`scripts/generate-samples.mjs`) or typed by hand for a test. None of it comes
from a real person, a real organisation or a real dataset, and none of it was
copied out of a production system.

Two rules keep it that way:

- **Domains are reserved.** Email addresses and URLs use `example.com`,
  `example.org`, `example.net`, `*.example` or `*.test` — names the IETF
  reserves for documentation (RFC 2606, RFC 6761) and that can never resolve to
  a real service. A new fixture must not introduce a real domain, a real company
  name or a real person.
- **Phone numbers are fiction.** The 555-01xx range and the +44 20 7946 0xxx
  test range, which are allocated to fiction.

`samples/dev/` holds the fixtures the test suite runs against.
`samples/heldout/` is intentionally empty: files dropped there are used to
re-score the rules on data they were never tuned for, and none are committed.

If you add a file, it must be synthetic too — this repository ships under the MIT
licence and its fixtures are published with it.
